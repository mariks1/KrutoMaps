# KrutoMaps Backend

Информационная система подбора недвижимости по критериям и окружению (POI)

## Описание

Данная информационная система предназначена для подбора объектов недвижимости (Realty) с учётом фильтров (цена, площадь, тип/сегмент и т.п.) и предпочтений по окружению (Place / POI — заведения/точки интереса).
Хранение и расчёты выполняются в PostgreSQL с расширением PostGIS: используется геометрия и пространственные функции, чтобы оценивать привлекательность объектов относительно POI.

## Основные функции

- Подбор топ-5 объектов недвижимости по фильтрам и предпочтениям/антипредпочтениям рубрик POI (весовой скоринг по расстоянию)
- Получение агрегатов по базе недвижимости (диапазон цен и площадей)
- Получение списка доступных рубрик POI
- CRUD-операции с объектами ``Place`` и ``Realty``
- Авторизация и регистрация пользователей (JWT)
- Разделение доступа по ролям (USER / ADMIN), защита эндпоинтов
- Миграции БД через Flyway (включая загрузку данных из CSV)
- Интеграционные тесты с реальной PostGIS БД через Testcontainers (end-to-end сценарии)

## Архитектура
- Java 21, Spring Boot 3.5 (Web, Security/JWT, Data JPA)
- PostgreSQL + PostGIS, Flyway для миграций
- MapStruct, Testcontainers

## Основные эндпоинты
- `POST /auth/sign-up` — регистрация (роль всегда USER, поле role игнорируется)
- `POST /auth/sign-in` — получение JWT
- `GET /api/rubrics` — список рубрик
- `GET /api/price-range`, `GET /api/area-range` — диапазоны цен/площади
- `POST /api/selection` — подбор топ-5 по фильтрам и предпочтениям
- Админ CRUD (только ADMIN): `/admin/places/**`, `/admin/realty/**`

## Особенности данных
- Геометрия: используется PostGIS-колонка `geom`, координаты `point_x/point_y` должны быть заполнены.
- CSV-загрузка (V3/V4) читает из `/csv`; в docker-compose это `./data` на хосте.
